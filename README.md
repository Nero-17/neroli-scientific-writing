# Neroli Scientific Writing

An author-informed editing skill for scientific drafts, including text generated by GPT. It revises the argument, exposition and language in a single workflow, based on writing choices in two mathematics papers by Nero Ziyu Li (also credited as Ziyu Neroli).

[中文说明](README.zh-CN.md)

This public package contains only paper-writing logic, language and style. It incorporates the manuscript guidance formerly in the local Nero-style skill. Research statements, applications, emails and non-paper translation remain in the author's separate local profile and are not distributed here.

## What it does

The default is a substantive revision of the supplied passage. The editor first reconstructs the scientific claim, then improves the sequence of ideas, revises the language, and compares the result with the original. Explicit requests for a light edit or faithful translation take precedence.

The central habits are concrete:

- Explain what the existing approach fails to establish before introducing another tool.
- Give definitions and formulas a purpose in the argument.
- Put explanation where the reasoning is difficult; leave immediate arguments short.
- Preserve the author's position while keeping proved, computed and conjectural claims distinct.
- Avoid unnecessary abbreviation variables in mathematical proofs.
- Follow the main theorem with a concrete worked calculation, showing how its quantities are evaluated and what the result means.
- Return usable revised text, with separate notes only for substantive changes or unresolved issues.
- Follow the author's paper structure: an abstract of at most five sentences, contents immediately afterwards, main theorem restatements with body numbers and a relevant figure in the introduction, and subdivisions chosen for the argument, without aiming for three subsections or matching counts across sections (never more than five).
- Give the introduction an engaging, concrete opening that leads to the paper's question, followed by orienting background, a single Main results subsection presenting the results in body-section order, and an accurate Lean formalisation subsection where applicable. Adapt this progression to the content; a historical opening is an example, not a requirement.
- Display formulas without boxes, preserving their mathematical content and references.

The skill is grounded most strongly in mathematics. Guidance for empirical science is explicitly an editorial extension. “Human” describes the intended reader-facing quality; it does not certify unaided authorship or make claims about AI detectors.

## Use

In a skill-capable coding agent, invoke:

```text
Use $neroli-scientific-writing to revise this introduction for a mathematics
journal. You may reorganise the prose, but preserve the scientific claims,
notation and citation keys. Give me the revised LaTeX first.

[paste the draft and relevant definitions]
```

For a lighter intervention:

```text
Use $neroli-scientific-writing for a faithful Chinese-to-English translation of a manuscript passage.
Preserve the order and emphasis; flag substantive mathematical issues
separately.

[paste the draft]
```

For a long manuscript, provide the source files and specify the sections to revise. The workflow keeps the larger structure and notation in view while editing locally. When using an ordinary chat without skill discovery, provide `SKILL.md` and the relevant reference files as instructions; it remains a model-executed workflow rather than a standalone program.

## Local installation

Clone the public repository into your personal skills directory:

```sh
git clone https://github.com/Nero-17/neroli-scientific-writing.git ~/.agents/skills/neroli-scientific-writing
```

If the previous `humanize-scientific-writing` skill is installed, move that old directory outside the skill discovery directory after installing this replacement so that both versions do not match the same task.

Place this directory, containing `SKILL.md`, at `~/.agents/skills/neroli-scientific-writing/` for personal Codex use, or at `.agents/skills/neroli-scientific-writing/` in a project. Keep the `references/` directory beside `SKILL.md`. Codex supports explicit skill invocation and automatic matching from the description; if a new skill does not appear, restart Codex. See the [official skills documentation](https://learn.chatgpt.com/docs/build-skills).

No API key, executable script, network connection or private source is required for ordinary use. Other hosts may use different installation paths.

## Evidence and validation

The source corpus is [arXiv:2212.01987v4](https://arxiv.org/html/2212.01987v4) and [arXiv:2603.13798v3](https://arxiv.org/html/2603.13798v3), together with the commissioning author's explicit preferences about proof notation and manuscript structure. This repository contains original instructions and synthetic examples, not copies of the papers or private personal-style records.

See the evidence file for the parts examined and the distinctions between observations and editorial design. See [the initial evaluation record](evals/initial-review.md) for what was actually checked. The examples and initial review are not a blind study, a measure of author similarity, or a guarantee of mathematical correctness.

Improve the skill using actual drafts and concrete author feedback. A useful issue identifies the task, the unwanted edit, and the preferred alternative; remove confidential content before making an example public.
