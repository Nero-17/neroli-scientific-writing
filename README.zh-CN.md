# Neroli Scientific Writing

把科学稿件（包括 GPT 生成的稿件）按 Nero Ziyu Li 的论述逻辑、语言选择和写作偏好统一修改的 skill。

本公开版本只包含论文写作，整合了原本放在 Nero-style 中的论文规则。研究陈述与申请、邮件和非论文中文表达及翻译继续保留在本地 Nero-style 中，不进入本仓库。

它以两篇数学论文为基础，将修改过程写成五个阶段：

1. **确认修改范围。** 默认允许实质性改写；明确要求轻改或直译时，保留原有推进方式。
2. **先弄清论证。** 识别研究问题、已有结果、具体障碍、解决方法、结论和限制，记录必须保留的数学内容。
3. **调整论述。** 让定义、引理、例子和公式有明确用途；复杂步骤保留推理，直接结果保持简短。
4. **修改语言。** 直白、具体，保留有根据的力度，删掉空泛宣传和重复说明，不增加非必要缩写变量。
5. **对照原稿。** 检查假设、量词、常数依赖、例外、符号、引用与结论状态有没有被悄悄改掉。

这些阶段是编辑时执行的工作，不会作为固定标题塞进论文。默认先交付改好的正文；实质修正或未解决的问题单独简述。

完整论文还遵循作者明确提出的结构规则：摘要尽量简短且不超过五句话；摘要之后立即放目录；引言直接重述主要定理并沿用正文编号，同时放解释模型的图；每个 section 最好至多有三个 subsection，每个 subsection 最好不少于三页。这是结构偏好，不是硬性配额：可以不分 subsection，也可以只有一个或两个，各 section 不必整齐划一。优先合并论证上确实相关的短小单元，保留必要证明与过渡；不能填充文字、编造内容、调整字号页边距或机械降低标题层级来凑数。页数以实际或预定排版为准，没有可靠排版时注明尚未核实。论证需要、期刊要求或当次明确指令可以构成例外，轻改和忠实翻译不擅自重排结构。

主定理后加入一个具体计算例子：明确对象和参数，实际算出定理中的量，并说明计算结果的含义。引言中的定理重述后可给精简计算，正文主定理后给完整推导；不能仅列举例子名称，也不能把有限近似写成精确极限。

Introduction 从引人入胜的具体问题、真实的猜想背景或其他数学切入点开场，自然引出本文要回答的问题。随后用 Background 交代方向进展，再用一个 Main results subsection 集中叙述主要结果，按正文 section 的先后顺序推进并沿用正文编号，用过渡段连接不同问题与结论，最后说明 Lean formalisation 的实际范围。这是可调整的写作方式，不强制历史开场或整套固定标题；主要结果内部仍按正文 section 顺序叙述，必要时可以在背景和定理之间介绍模型。没有形式化材料时应指出缺失，不能编造已验证的结论。

公式不使用公式框；已有的框只去掉展示性边框，保留数学内容、公式编号和交叉引用。

几何引理可以先用简短开头交代必要对象，再按实际操作逐步说明，每步说明后紧接对应配图，最后用引理收束已经完成的证明，不重复推导。减少零碎的独立公式；图内优先用符号，位移和位置向量用箭头表示，需要时加入坐标，并以淡色母图保留几何背景。删除没有新增信息的图。三步、三张图和半页开头是具体任务中的选择，不是所有论文的固定模板。详见[几何推导与证明配图](references/proof-figures.md)。

## 从连续修改中形成的写作方式

核心是让读者顺着作者的数学思路理解，而不是先堆出形式语言，再补解释。

- **先用语言找到实际操作。** 弄清哪些对象相交、做了什么变换、什么保持不变、哪个量继续演化，再安排公式与配图。小节开头可以按“留下了什么问题—从哪里入手—得到什么结论”推进；三句话不是固定模板。
- **让不同环境各司其职。** Definition 定义对象，紧接的 Example 展示怎样构造它，Theorem 简洁陈述条件与结论，Proposition 单列等价条件。等价证明逐条写清蕴含方向。顺序服从逻辑依赖，不机械套用。
- **把篇幅花在第一次理解上。** 关键例子应让读者先看图，再自行读出转移表，最后由表得到矩阵。后面若只是代入已经算出的谱半径求维数，一句话即可，不重算一遍。
- **符号少，但含义必须显式。** 参数集合不自动等于几何集合的并；表格里的标签集合不等于求和。说明行列分别是谁、转移方向是什么、矩阵元素如何计数。向量零也使用箭头，数字标签和矩阵里的零保持标量写法。
- **名称帮助理解，定义保证准确。** 优先用说明几何意义的名称；采用直观新名称时给出精确条件，并区别已有近义概念。全篇改名要检查摘要、标题、图注及否定形式，不能只做字符串替换。
- **图承担具体解释任务。** 图内少文字，用符号、坐标、完整对象和必要的淡色背景定位关系；晶格图同时展示粗细网格，并区分格点包含与连线重合。有限示意不能代替一般证明，图应在对应命题或步骤处引用。
- **按指定范围完成修改。** 局部 opening 修改保留作者的推进顺序，跨语言版本不擅自同步。完成后核对数学含义、引用和实际排版；不能把编译通过或局部形式化说成全文证明正确。
- **重组不等于丢掉旧稿。** 按新目录搬入旧版仍适用的 introduction、基础性质、定义与证明；保留作者明确选定的文字，不恢复已被撤回的数学主张。尊重“先不要动某节”等范围限制，并检查必要的前后文一致性。
- **直译保留作者的表达形式。** 明确要求按中文翻译时，保留括号、疑问句、强调方式和推进顺序；作者指定的 `【...】` 是修改评论，执行后不留在成稿里。不能借翻译另写一套动机或加强结论。
- **先观察，再分类。** 先介绍物理或几何观测量、取样与平均方式和存在范围，再给出表达式定理，最后推导分类与更少不变量的等价性。不能为了恢复几个维数倒着定义指数。准确区分点态与平均、累计尾与点概率、证明提纲与完整证明，以及引用与新增结果。
- **表格简洁，caption 要短。** 多个量的情况可以在小节开头用总表交代，再逐项定义。按要求转置、分组加隔板；表格和例子中的近似数值默认四位小数，保留有解释力的解析式和严格界所需精度。图要实际看排版、对齐与间距；只编号一个面板的要求不自动扩展为其他图的规则。
- **定义和自己的结论不加说明性方括号标题。** 默认写 `\begin{proposition}\label{...}` 或 `\begin{definition}\label{...}`。结果环境的 `[...]` 留给来源归属或明确要求的比较、推广说明；解释性名称放在正文中，保留编号和 label。简短的 `Also see` 比较可以不带结论编号；证明直接依赖的文献结果仍应在合适位置给出必要定位。
- **标题和摘要要简短、有力度。** 不为技术上的面面俱到堆叠限定词，也不擅改作者选定的标题。必要的准确性不能丢；有依据的 `disprove` 等强表述也不应自动削弱。
- **每节要有一个看得见的目标。** 避免堆结论；子类和旁支只有在推进机制或说明边界时才保留。已证明的量直接回顾，短 opening 不必独立成 subsection；次要的条件结果可移入 appendix，正文保留准确说明和引用。
- **物理意义要讲清楚。** 说明定理支持或否定了哪一种物理期待，以及跨学科工具实际解决了哪一步。摘要、main results 和正文可以分别承担概括、动机和论证，不能机械重复同一句宣传。
- **短证明不要频繁分黑体步骤。** 半页以内通常连贯写完；一页以上且确实有不同阶段时再用黑体组织。证明的难度来自关键论证，不靠标题、分行或篇幅制造。
- **Discussion 可以有个人判断。** 先说明结果改变了什么，再提出具体 open problems。保留作者提供的信念与希望，但明确它不是已证明的结论；不能把否定某种分类标准写成否定所有 universality。
- **正文讲机制，仓库承载大体量核验材料。** 大型证书、逐项配置和代码可以放仓库，但正文必须说明检查什么、为什么足以推出结论。区分前人的物理认识与本文的新严格论证，既不因证明不同忽视前人，也不因数值接近宣称模型已经等价。
- **布局帮助理解。** 优先考虑正常的 top/bottom 浮动而非全部 `[H]`；图的交叉不能被误读为顶点。定义可用紧凑编号列项，维数要带上所测对象，不能把 ambient 和 cluster 混在一起。

这些原则细化了已有规则，不增加非必要缩写变量，也不把某篇文章的三步、图数、角度或命名变成通用要求。

## 调用示例

```text
用 $neroli-scientific-writing 修改下面这段 GPT 写的论文引言。
可以调整论述顺序，按我的逻辑和语言重写；保留数学主张、记号和引用。
先给我能直接放进论文的 LaTeX。
```

```text
用 $neroli-scientific-writing 检查这段证明的表述。
把真正困难的步骤解释清楚，不要增加非必要缩写变量。
发现不能成立的推理时单独指出，不要用润色遮住它。
```

```text
用 $neroli-scientific-writing 忠实翻译这段中文论文。
这次只做必要修改，保留原稿顺序和语气。
```
